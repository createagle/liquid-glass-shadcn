测试 1 · feImage 酸性测试 （最重要）

红框区域的 backdrop-filter 里只有一个 feImage，它加载了一张纯洋红色图片。 如果 feImage 正常工作，这块区域会被洋红色整个盖住。这决定了本项目的折射方案能不能用。

通过 = 红框内是一整块纯洋红色 失败 = 红框内还是黑白条纹

测试 2 · 对照组（已知可用）

同样是 backdrop-filter: url(...)，但位移图来自 feTurbulence 而不是 feImage。 这一格应该是通过的。它的作用是证明「backdrop-filter 引用 SVG 滤镜」这条路本身没问题， 从而把测试 1 的失败精确定位到 feImage 一个原语上。

通过 = 条纹被扭成明显的波浪 / 火焰状 失败 = 条纹笔直，毫无变化

测试 3 · corner-shape: squircle

两个方块圆角值完全相同（44px），左边多加了一行 corner-shape: squircle。 如果浏览器支持，左边会是 Apple 那种「更方、更平缓」的连续曲率角，右边是标准圆弧角。

通过 = 左右两个方块的角明显不一样 失败 = 左右两个长得一模一样
左：squircle
右：border-radius
