@glass/core Token 速查

Phase 2 产出。三层 token 体系 + 材质档位 × 明暗的 8 宫格表现。

1. 材质表现：4 档位 × 明暗 = 8 宫格

这是 Phase 2 的核心验收项。每格是同一个「Layer B 磨砂底座 + Layer I 指示器」压在同一张彩色背景上， 只有材质档位与主题不同。档位只影响底座，不影响指示器的折射强度（PROJECT_SPEC §8）—— 所以四格里指示器的玻璃感应当保持一致，变化的是底座的通透度。

2. iOS 系统色

⚠️ 可信度 [待核实 · 社区通行值]，不是 [官方]。Apple 明确写着 “Avoid hard-coding system color values… The actual color values may fluctuate from release to release.” 这里硬编码是 Web 端的无奈选择，取值随主题自动切换。

3. 灰阶（systemGray 家族）

4. 标签色 / 分隔线 / 填充

这些必须是带 alpha 的形式而不是实色 —— 它们要透出下面的玻璃材质， 换成实色会立刻失去 iOS 的观感（PROJECT_SPEC §6）。

5. 内容层标准材质

PROJECT_SPEC 未覆盖，研究阶段补入。Apple 原文：内容层继续提供 ultra-thin / thin / regular / thick 四档标准材质。 内容型组件（Card / Table / List）用这一组，不用 Liquid Glass。

6. 圆角与连续曲率

7. 同心圆角 concentricRadius()

Apple 的定义是「子角与父角共圆心」，推出 子半径 = 父半径 − 内缩。 但还有两条 PROJECT_SPEC 没写的：逐角解析，以及离容器角太远时半径归零（变方角）， 逃生口是 minimum。
